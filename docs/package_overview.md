# Package Overview — Price-My-Car (AutoIntel)

Inventory of every module in the repository (post-restructure).

## 1. Application package (`app/`)

| Module | Responsibility | Entry point |
| --- | --- | --- |
| `app/__init__.py` | Marks `app` as an importable package. | — |
| `app/streamlit_app.py` | Streamlit dashboard: auth (bcrypt + `users_db.json`), 9 pages, admin panel, demo-mode fallback. | `streamlit run app/streamlit_app.py` |
| `app/helpers.py` | Pure functions: `fmt_inr`, `get_price_tier`, `make_prediction`, `ensemble_prediction`, `shap_lite_approximation`, `compute_deal_score`, `generate_data_quality_report`, `generate_natural_language_explanation`, constants (`MODEL_METRICS`, `METRICS_DF`). | — (library) |

**Framework coupling**: Streamlit only in `streamlit_app.py`; `helpers.py` is deliberately Streamlit-free for testability.

## 2. Scripts (`scripts/`)

| Module | Category | Responsibility | Entry point |
| --- | --- | --- | --- |
| `scripts/backfills/prepare_ml_data.py` | Backfill | CSV → log1p transform, feature engineering (39), train/test split → `ml_ready/*.npy` + `preprocessor.pkl` | `python scripts/backfills/prepare_ml_data.py` |
| `scripts/seed/tune_hyperparameters.py` | Seed | GridSearchCV (GB/XGB/RF) → tuned models + `*_gs_results.json` | `python scripts/seed/tune_hyperparameters.py` |
| `scripts/seed/train_dashboard_models.py` | Seed | Trains 8 models with tuned params → `ml_ready/models/*.pkl` | `python scripts/seed/train_dashboard_models.py` |
| `scripts/admin/generate_report.py` | Admin | EDA HTML report → `report_output/` | `python scripts/admin/generate_report.py` |
| `scripts/admin/create_notebook.py` | Admin | Generates `notebooks/car_price_ml_comparison.ipynb` | `python scripts/admin/create_notebook.py` |
| `scripts/admin/debug_dtypes.py` | Admin | Prints CSV dtypes (debug aid) | `python scripts/admin/debug_dtypes.py` |

## 3. Tests (`tests/`)

| Module | Responsibility |
| --- | --- |
| `tests/__init__.py` | Package marker — lets pytest prepend repo root to `sys.path` (resolves `app.helpers`). |
| `tests/test_helpers.py` | 65 unit tests: formatting, price tiers, filtering, prediction, ensemble, deal score, data-quality report, model-metrics integrity. |
